# GitHub project

- Repository: https://github.com/Mustafamgbng/studioshelf
- Visibility: private
- Default branch: `main`
- Editorial design revision: `design/editorial-brand-refresh`

The starting working application is on `main`. The editorial design, original logo and generated photographic examples are delivered as a pull request. Future changes should use a feature branch and pull request as recorded in `AGENTS.md`.

This source package includes no API credentials. Configure your own services using `.env.example` and the setup guide.
