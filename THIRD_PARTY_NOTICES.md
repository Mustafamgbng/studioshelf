# Third-party components

Application source, the StudioShelf logo, and the legacy mug illustration were authored for this project. The current headphones, fragrance and tote photographs are AI-generated concept assets; see `docs/ASSET_PROMPTS.md` for prompts and provenance. No stock photography or proprietary design template is included. All sample brands and products are fictional. System fonts are used; no remote font request is required. SimpleByNoor and Linear were consulted as visual references; their branding, copy and assets are not included.

The application depends on third-party packages including Next.js, React, React DOM, Supabase JavaScript, JSZip and Lucide React.
